# Папка `plans/`

Это место для **технических планов реализации функций** — здесь описывается, *как* мы делаем проект.

## Правила

1. **Один план = одна функция.** Если план уже есть — работаем с ним, не плодим дубли.
2. **Имя файла:** `YYYY-MM-DD-название-функции.md` (например, `2026-07-02-режим-квиза.md`).
3. **Фазы.** Каждый план делится на фазы. У каждой фазы статус:
   - `[ ]` — не сделано,
   - `[x]` — сделано.
4. **Итоговый блок** в конце плана: реализована функция целиком или нет, и что осталось доделать.
5. **Актуализация обязательна.** Любой агент, работающий с планом, отмечает выполненные фазы и дописывает, что сделал — после каждой сессии.
