# План: наполнение базы дат (пакетный черновик)

**Дата:** 2026-07-03
**Функция:** добавить в `data.js` оставшиеся даты школьного курса истории (~87 штук) в уже существующем формате карточек. На этом шаге заполняем только `date` и `events` (формулировку события); `context` и `lifehack` — пустые заглушки, заполним позже.

**Стек:** тот же (HTML + CSS + JS, данные в `app/data.js`).

## Зачем

Каркас тренажёра готов на 3 карточках. Чтобы двигаться дальше (ассоциации, квиз по всему списку), нужен полный список дат в структуре. Тексты-запоминалки (`context` + `lifehack`) сочиняются отдельно и медленнее — поэтому сначала заливаем «скелет» из дат и формулировок, потом наполняем содержанием.

## Что сделано

В массив `CARDS` (`app/data.js`) после 3 готовых карточек добавлены карточки с `id` 4–90 (всего в базе стало 90 карточек). Каждая новая карточка повторяет формат готовых:

- `date` — дата. Одиночные годы: «907 год»; периоды: «964–966 годы» (тире `–`); десятилетия: «1650-е годы», «1890-е годы»; особый случай «1725–1762 (1801) годы».
- `events` — массив с одной формулировкой события (как в шаблоне).
- `context: ""` и `lifehack: ""` — пустые заглушки (заполним позже).
- `character` — 🐱/🐶 чередуются.
- `options` / `answer` — технические поля квиза заполнены минимально: `answer` = дата, `options` = `[дата]` (один вариант-заглушка). Полноценные варианты ответа допишем позже.
