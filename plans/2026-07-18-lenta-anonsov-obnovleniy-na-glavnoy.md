# План: лента анонсов обновлений на главном экране

## Что делаем
На главном экране навигации (`#screen-menu`), сразу после блока со статьёй
«Как учить даты без стресса» (`.guide-link-wrap`), добавляем тонкую спокойную
полоску, в которой по очереди, с плавным затуханием/появлением (без бегущей
строки), показываются сообщения из данных changelog. Клик по полоске открывает
уже существующую модалку «Что нового».

## Источник данных
Массив `CHANGELOG` из `changelog.js` (тот же, что и в разделе «Что нового»).
Каждая запись: `{ id, date, title?, items: [...] }`. Разворачиваем в плоский
список сообщений: для каждой записи — по одному сообщению на каждый пункт
`items`, вида `🎉 Обновление {date}: {item}`. Порядок — как в массиве
(свежее → старое), после последнего возврат к первому (цикл).

## Поведение
- Одно сообщение висит статично ~5 секунд.
- Затем текущее плавно исчезает (fade out), следующее плавно появляется (fade in).
- Никакого горизонтального движения — только смена прозрачности.
- Клик/Enter по полоске → `openChangelog()` (та же модалка).
- Если сообщений нет — полоска скрыта. Если ровно одно — показываем без цикла.
- `prefers-reduced-motion`: смена мгновенная, без анимации.
