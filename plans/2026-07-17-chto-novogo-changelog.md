# Раздел «Что нового» (changelog)

Ненавязчивый вход в журнал обновлений в верхней панели — по образцу Notion / Linear / Duolingo.
Компактная иконка-искра рядом с переключателем звука, точка-бейдж непросмотренных обновлений,
модалка со списком записей (свежее сверху). Новые записи добавляются одной строкой в данных,
без правки интерфейса.

## Фаза 1. Данные — отдельный файл `changelog.js` [x]

- [x] Массив `CHANGELOG`, свежее — первым элементом.
- [x] Поля записи: `id` (стабильный ключ для «непросмотренности», формат ГГГГ-ММ-ДД),
      `date` (человекочитаемая дата), `title` (необязательно), `items` (список изменений).
- [x] Первая запись на 17 июля 2026 с 4 пунктами (лайфхаки, фильтр «Сложные», скролл фона, список дат).
- [x] Подключение в `index.html` перед `app.js`.

## Фаза 2. Интерфейс [x]

- [x] Кнопка `#changelog-btn` (иконка-искра) в `.topbar-right` перед переключателем звука.
- [x] Точка-бейдж `#changelog-dot` с мягкой пульсацией (учтён `prefers-reduced-motion`).
- [x] Модалка `#changelog-modal` со списком `#changelog-list`, открывается через общий `openModal`
      (блокировка скролла фона наследуется автоматически).
- [x] Стили в едином визуальном стиле: акцентная дата, точки-маркеры пунктов, разделители записей.

## Фаза 3. Логика бейджа [x]

- [x] `hq_changelog_seen_v1` в localStorage хранит id последнего просмотренного обновления.
- [x] Бейдж горит, пока id самой свежей записи ≠ сохранённого (или ничего не сохранено).
- [x] При открытии модалки id свежей записи записывается как просмотренный → бейдж гаснет.
- [x] `updateChangelogBadge()` вызывается при запуске приложения.

## Отменено / отложено

- Бегущая строка (тикер) на экране меню как второй вход — сделана, затем убрана по просьбе:
  выглядела слишком заметно. Идею отдельного, более тихого второго входа обдумываем позже.

## Как добавить новое обновление в будущем

Вставить новый объект **первым** элементом массива `CHANGELOG` в `app/changelog.js`.
Больше ничего менять не нужно — интерфейс и бейдж подхватят запись автоматически.
