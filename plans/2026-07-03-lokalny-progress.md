# План: локальный прогресс ученика (localStorage)

**Дата:** 2026-07-03
**Функция:** сохранение прогресса ученика полностью на клиенте (localStorage), без сервера, базы и внешних запросов.

## Что входит

1. **Общий прогресс** — сколько дат выучено из общего числа (+ полоса).
2. **Статистика по каждой дате** — количество верных и неверных ответов.
3. **Авто-список «сложные даты»** — дата попадает при 2+ ошибках; уходит после 2 верных подряд.
4. **Streak** — счётчик дней занятий подряд.
5. **Сброс прогресса** — с подтверждением (модалка), чтобы не сбросить случайно.

## Модель данных

Всё в одном объекте `localStorage`, ключ `hq_progress_v1`:
```
{ dates: { <id>: { correct, wrong, streak, hard } }, streakDays, lastVisit }
```
- `streak` — верных ПОДРЯД сейчас; `wrongStreak` — ошибок ПОДРЯД; `hard` — флаг «сложная».
- **«Выучено»** = `streak >= 3` (3 верных подряд без ошибок между ними). Ошибка обнуляет `streak` — статус слетает.
- **«Сложная»** = `wrongStreak >= 2` (2 ошибки ПОДРЯД); снимается при 2 верных подряд.
- Пороги уточнены в доработке окна «Мой прогресс» — см. `2026-07-03-dorabotka-okna-progress.md`.

## Найденный и исправленный баг

Модалка сброса показывалась сразу: правило `.modal-overlay { display:flex }` шло в CSS позже `.hidden { display:none }` при одинаковой специфичности и перебивало его. Починено правилом `.modal-overlay.hidden { display:none }`.
