# План: черновая версия тренажёра ХроноКвест (3 даты)

**Дата:** 2026-07-02
**Функция:** рабочий прототип тренажёра на 3 датах с режимами «Обучение» и «Квиз».

**Стек:** HTML + CSS + JavaScript (статический сайт, без БД и API). Данные — в `data.js`.

**Контент 3 дат:**
1. VI–VIII века — расселение славян на три ветви.
2. 862 год — призвание варягов, Рюрик в Новгороде.
3. 882 год — поход Олега на Киев, образование Древнерусского государства.
Тексты получены от пользователя (2026-07-03) и вставлены в `data.js`.
Каждая карточка теперь = два блока: `context` (контекст) + `lifehack` (лайфхак-приём).

## Как поправить тексты карточек

В файле `app/data.js` у каждой карточки два поля — `context` (контекст) и `lifehack` (лайфхак-приём). Заменить текст в кавычках на нужный, остальное не трогать.
