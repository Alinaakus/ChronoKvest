# План: более выразительный пиксельный маскот (котик)

Дата: 2026-07-07
Функция: усилить выразительность котика-маскота — мимика, анимации, моргание, «дыхание»,
вариации выражений. Силуэт и палитра прежние (доработка, не редизайн).

## Что и где
Код маскота — в `app/app.js` (пиксельная карта `CAT`, `FACES`, `catRows`, `catSVG`,
`liveCat`, `renderMascot`, `renderMenuMascot`, hero-peek) и `app/styles.css` (анимации
`.mascot`/`.cat-stage`, keyframes). Три состояния: idle (покой), happy (верный ответ),
think (неверный ответ / задумчивость). Показывается в квизе, в меню (brand) и на hero.

## Решения
1. **Крупные глаза 2×2 с бликом** в базовой (idle) морде — дружелюбный «живой» взгляд
   вместо мелких «пустых» глаз. Строки карты 4–5 переопределены.
2. **Мимика по состояниям** (меняем только глаза/брови/щёки, силуэт один):
   - idle — большие глаза, спокойно-любопытный взгляд;
   - happy — зажмур «^^», приподнятые бровки, розовые щёки;
   - think — прищур/полуприкрытые глаза, приподнятая бровь (сомнение).
3. **По 2 варианта** на каждое состояние (`FACES[expr][0|1]`), выбор случайный
   (`randVariant`) — реакция не повторяется один в один.
4. **Моргание** — редкое случайное в покое: `liveCat(wrap,key,px)` по таймеру подменяет
   глаза на закрытые (`BLINK`) на ~130мс. Пауза 2.6–6.8с случайная. Уважает
   prefers-reduced-motion (без морганий). Реестр таймеров `catBlinkTimers` по ключу
   (quiz/menu/hero), чтобы не плодить циклы; проверка `wrap.isConnected`.
5. **«Дыхание»/покачивание** — CSS на СТАБИЛЬНОЙ обёртке (её моргание не пересоздаёт):
   `@keyframes idleBreathe` (лёгкий подъём + масштаб) на `.mascot--idle .cat-stage` и на
   `#menu-mascot`; hero — прежний `peekbob`.
6. **Анимации реакций усилены**: `dance` — бодрое подпрыгивание с покачиванием головы;
   `ponder` — покачивание из стороны в сторону (сдвиг + наклон).

## Фазы
- [x] Фаза 1. Система выражений: `FACES` (idle/happy/think ×2 варианта), крупные глаза,
      `catRows`/`catSVG` с вариантом и морганием. Проверено контактным листом (headless).
- [x] Фаза 2. «Живой» котик: `liveCat` (моргание по таймеру + reduced-motion guard),
      подключён в quiz-idle, меню и hero. `renderMascot` рисует реакцию без морганий.
- [x] Фаза 3. CSS-анимации: `idleBreathe` (дыхание) для quiz-idle и меню, усиленные
      `dance` и `ponder`.
- [ ] Фаза 4. Живая проверка в браузере (моргание, дыхание, подпрыгивание, покачивание,
      смена вариантов при повторных ответах).

- [x] Фаза 5. Доводка по обратной связи: (1) глаза сделаны ДОБРЫМИ — белок (W) + зрачок
      (E), покой = взгляд вперёд, задумчивость = взгляд вверх-вбок (а не тяжёлый прищур),
      радость = подмигивание (один глаз прищурен) + румяные щёки. (2) Симметричная пара
      боковых искр `fx--happy` (s1/s2) убрана — осталась ОДНА искра над головой (s3),
      асимметрия объясняется подмигиванием. Все состояния сверены контактными листами.

- [x] Фаза 6. Радость — только мордочкой, без плавающих элементов: искры `fx--happy`
      (и s3, и keyframes `spark`) удалены полностью. Радость = симметричные закрытые глаза
      дугами «^ ^» + улыбка (в карту добавлен рот, стр.7–8) + румяные щёки; без подмигивания,
      оба глаза одинаковы. Два симметричных варианта улыбки (дуга/широкая линия) для
      разнообразия. Сверено контактными листами и снимком в контексте квиза.

- [x] Фаза 7. Откат мимики РАДОСТИ (по просьбе пользователя). Все правки лица радости
      (закрытые/дугами глаза, щёки, разные формы рта, искры/звёздочки) убраны. `FACES.happy`
      = `[ {} ]` (пустой оверрайд = то же нейтральное лицо, что в покое). Радость теперь
      передаётся ТОЛЬКО анимацией `dance` (подпрыгивание) + репликой в облачке. Проверено
      попиксельно: лицо happy идентично idle v0. Моргание/дыхание/выразительность
      нейтрального лица и состояние think НЕ трогали (think = взгляд вверх-вбок, оставлен).

## Итог
Реализовано по коду (фазы 1–3, 5, 7). Радость больше не меняет лицо — только анимация +
облачко. Осталась живая проверка в браузере (фаза 4).
