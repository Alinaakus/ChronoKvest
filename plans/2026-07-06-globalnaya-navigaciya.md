# План: сквозная навигация по приложению

## Что делаем
1. **Закреплённая верхняя панель (sticky topbar)** — видна во всех четырёх разделах
   (Обучение, Квиз, Режим карточек, Мой прогресс), НО не на hero и не в меню. Содержит логотип
   (клик → меню) и компактные ссылки на все разделы: переход в один клик из любого места.
2. **Режим обучения:** «Далее» на месте; добавить «Назад» слева со 2-й карточки; убрать кнопку
   «Меню» из экрана (теперь она в topbar); добавить быстрый переход к ЛЮБОЙ дате — компактная
   кнопка, разворачивающая список всех дат (поиск + клик), не занимает постоянного места.
3. **Мой прогресс:** список 101 даты слишком длинный → пагинация по 20 дат (компактно, с
   переключателем страниц). Кнопку «Меню» из экрана убрать (есть topbar).

## Почему так
- Topbar даёт мгновенную межраздельную навигацию и снимает необходимость возвращаться в меню.
  Активный раздел подсвечивается своим цветом (связь с цветовой схемой режимов).
- Быстрый переход к дате — модалка со списком и поиском: компактный триггер, список по запросу.
- Пагинация (а не «показать ещё») держит список всегда коротким и ограниченным — лучший ответ на
  «долгий скролл». По 20 — умещается без прокрутки.

## Фазы
### [x] Фаза 1. Sticky topbar
- HTML: `<nav id="topbar">` (логотип + 4 ссылки с иконками) первым в `.app`.
- CSS: sticky, backdrop-blur, нижняя граница; активная ссылка — цветом раздела; на мобилке иконки без подписей.
- JS: `updateTopbar(name)` из `showScreen()` — прячет на hero/menu, подсвечивает активный раздел.

### [x] Фаза 2. Обучение: Назад + быстрый переход
- HTML: контролы `Назад | Далее`; кнопка-триггер «Перейти к дате»; модалка `#jump-modal` (поиск + список).
- JS: `learnPrev()`; в `renderLearnCard()` прятать «Назад» на первой карточке; `openJump/closeJump/renderJumpList/jumpTo`.
- Убрать «Меню» из экранов Обучение/Квиз/Карточки.

### [x] Фаза 3. Прогресс: пагинация
- HTML: блок `#pager` (‹ · инфо · ›) в карточке списка; убрать «Меню» из контролов.
- JS: `progressPage` + размер страницы 20; пагинация в `renderProgress()`; `progPrev/progNext`;
  сброс страницы при входе и смене фильтра.

### [x] Фаза 4. Проверка
Синтаксис JS — `node --check` ОК. Открыто в Chrome. Ручная проверка переходов за пользователем.

## Итог
Реализовано целиком.
- **Topbar:** `<nav id="topbar">` с логотипом (→ меню) и 4 ссылками; `updateTopbar()` прячет его на
  hero и в меню, подсвечивает активный раздел его цветом; на мобилке — иконки без подписей.
- **Обучение:** «Назад» слева (скрыта на 1-й карточке через `visibility`), «Далее» на месте; кнопка
  «Меню» убрана со всех разделов (её роль — у topbar); быстрый переход — `#jump-modal` с поиском
  по году/событию, триггер `.jump-btn` (список только по запросу).
- **Прогресс:** пагинация по 20 (`PROG_PAGE_SIZE`), панель `#pager` с ‹/› и «N–M из K»,
  сброс страницы при входе и смене фильтра.
Логика прогресса и режимов не менялась. См. связанные: [[2026-07-06-rezhim-vspomni-i-perevernut]],
