# План: Мобильное поведение «как приложение»

## Цель
Убрать «веб-страничное» поведение на мобильных: запретить зум жестами и исключить горизонтальный выход элементов за пределы экрана. Сайт должен ощущаться как нативное приложение.

## Фазы

- [x] Фаза 1. Viewport-тег: добавить `maximum-scale=1.0, user-scalable=no` в `app/index.html` — запрет зума щипком и двойным тапом.
- [x] Фаза 2. Apple/мобильные мета-теги для запуска «как приложение» с домашнего экрана: `apple-mobile-web-app-capable`, `apple-mobile-web-app-status-bar-style`, `mobile-web-app-capable`.
- [x] Фаза 3. CSS против горизонтального переполнения: `overflow-x: hidden` на `html` и `body` + `width/max-width: 100%` на `body` (`app/styles.css`).
- [x] Фаза 4. Проверка CSS (скобки сбалансированы) и тест на реальном телефоне: зум и горизонтальный скролл отсутствуют.

## Что проверено в CSS
Структурных «широких» элементов нет: ширины через `max-width`, `box-sizing: border-box` глобально. Отрицательные margin у `.topbar` — намеренный full-bleed ровно на величину padding (20px). `overflow-x: hidden` служит страховкой.
