# План: иллюстрации-персонажи в карточках обучения

**Дата:** 2026-07-03
**Функция:** подключать к карточке обучения авторскую иллюстрацию (если она есть у даты), в «эппловском» стиле — сверху карточки как обложка.

## Первая карточка

`slavyane1.png` (1672×941, ~16:9) — три котёнка в славянских нарядах на распутье Восток/Запад/Юг → дата VI–VIII века (расселение славян на три ветви, id 1).

## Механика (расширяемая на будущие даты)

- В `data.js` у карточки добавляем поле `image` (путь) и `imageAlt` (описание). Нет поля — картинки нет, блок скрыт.
- Путь от `app/index.html`: `../public/images/characters/slavyane1.png`.

## Ключевые правки

- **data.js** — у карточки id 1 поля `image`, `imageAlt`.
- **index.html** — в `.card` обучения первым элементом контейнер `<div class="card-illustration" id="learn-illustration">`.
- **app.js** — в `renderLearnCard()`: если `card.image` — вставляем `<img>`, иначе очищаем (у других дат картинок пока нет).
- **styles.css** — `.card-illustration img`: ширина 100%, `max-width` ~560px, скругление 18px, мягкая тень, тонкая рамка; `:empty` — скрыт. Расположение — сверху карточки, по центру.

## Итог

**Реализовано целиком.** Иллюстрация `slavyane1.png` подключена к карточке VI–VIII века как обложка сверху. Механика расширяемая: чтобы добавить картинку другой дате — положить файл в `public/images/characters/` и вписать `image`/`imageAlt` в её карточку в `data.js`, разметку/логику менять не нужно.

**На будущее:** файл тяжёлый (~2.9 МБ, 1672×941) — при желании можно сжать/уменьшить для скорости загрузки. Картинки для остальных дат добавляются тем же способом.

## Вторая карточка: 1812 (id 52) + оптимизация

- Оптимизация: `sips` не пишет WebP (только читает), Pillow нет → сконвертировал в **JPEG q80**: `1812.png` 2.45 МБ → `1812.jpg` **490 КБ** (в 5 раз легче). Оригинал PNG оставлен как исходник (можно удалить).
- В `data.js` у id 52 добавлены `image: "../public/images/characters/1812.jpg"` и `imageAlt`.
- CSS `.card-illustration` доработан под ОБА формата: контейнер `max-width:560px`, у `img` — `max-width:100%` + `max-height:520px` (горизонтальные упираются в ширину, вертикальные — в высоту). Регрессии у славян нет (проверено скриншотом).
- Проверено headless-скриншотами (1812 и славяне).

**Важно:** у карточки 1812 поля `context`/`lifehack` пока пустые (даты id 13–90 ещё не наполнены) — на карточке видны пустые блоки «Контекст»/«Лайфхак». Заполним, когда пользователь пришлёт тексты.

**Заметка по инструментам:** для будущих WebP понадобится `cwebp`/Pillow/ImageMagick (сейчас их нет); пока оптимизируем через встроенный `sips` в JPEG.
