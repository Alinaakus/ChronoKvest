# План: два экрана — посадочный (hero) и меню (хаб)

**Дата:** 2026-07-03
**Функция:** разделить главную на два экрана — эмоциональный посадочный (знакомство) и функциональный хаб (выбор действия).

## Логика разделения

**Экран 0 — посадочный (`#screen-hero`), эмоциональный:**
- только: кот (выглядывает сверху, КРУПНО), «машина времени» → «ХроноКвест» (КРУПНО), слоган «Запоминай даты играючи» (КРУПНО), одна кнопка «Начать путешествие во времени».
- убрано: эмодзи-карта (лого), огонёк-streak, точки-путь, кнопки режимов.
- центрирован по вертикали, крупные размеры — яркое первое впечатление.

**Экран 1 — меню (`#screen-menu`), функциональный:**
- заголовок «ХроноКвест» (текст, без маскота, стандартный размер).
- индикатор серии рядом со сводкой прогресса.
- три кнопки: Обучение / Квиз / Мой прогресс.
- точки-путь тоже здесь.
- всё компактное, стандартных размеров.

## Ключевые правки

- **index.html** — убрана `.topbar`; добавлены `#screen-hero` (класс `hero--big`) и `#screen-menu`; `#path` оставлен глобальным; кнопки «← Меню»/«В меню» → `goMenu()`.
- **styles.css** — `.hero-screen` (центрирование), `.hero--big` (крупные размеры), `.hero-slogan`, `.btn-cta`; `.menu-title`, `.menu-stats`, `.streak-badge`; `.hero` получил `width:100%`.
- **app.js** — `showScreen` знает экраны `hero/menu`, прячет точки-путь на hero; `goHome`→`goMenu`; старт с `showScreen("hero")` + `playHero()`; кот в hero крупнее (168px); streak с понятной подписью и склонением (`dayWord`, `renderStreak` → «🔥 3 дня подряд»).

## Streak-индикатор

Понятный без пояснений: `🔥 <N> <день/дня/дней> подряд`. Склонение проверено (1 день, 2 дня, 5 дней, 21 день, 111 дней).

## Найденные и исправленные баги

1. Название «ХроноКвест» вставало вертикально: во flex-центре ширина `.hero` схлопывалась (внутри всё absolute). Починено `width:100%` у `.hero`.
2. `goMenu()` не прятал hero (оба экрана видны): `.hero-screen{display:flex}` перебивал `.hidden{display:none}` (одинаковая специфичность, порядок). Починено — `.hidden` теперь `display:none !important` (заодно устраняет тот же класс проблемы для модалки).
