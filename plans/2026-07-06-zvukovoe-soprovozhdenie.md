# План: звуковое сопровождение интерфейса (Web Audio API)

Дата: 2026-07-06
Функция: короткие синтезированные звуки интерфейса, генерируемые кодом через Web Audio API
(без внешних аудиофайлов), в единой звуковой палитре. Плюс переключатель звука в верхней
панели с сохранением выбора в localStorage.

## Зачем
Мгновенная позитивная обратная связь (принцип из CLAUDE.md): звук усиливает эмоцию верного
ответа и мягко смягчает ошибку. Но звук — не для всех, поэтому обязателен выключатель.

## Звуки (единая палитра: мягкие triangle/sine + короткое «колокольное» затухание)
1. **Квиз (самые выразительные):**
   - Верный: восходящее арпеджио до-мажор (C5–E5–G5–C6), triangle — празднично; играет
     вместе с реакцией «happy» маскота.
   - Неверный: мягкая нисходящая пара нот (G4→Eb4), sine — по-доброму, без «buzzer»; играет
     вместе с реакцией «think».
2. **Меню:** очень тихий короткий блип при hover на карточку режима (не раздражает при
   многократном наведении).
3. **Hero:** «отправление» на кнопке «Начать путешествие» — восходящий тон + шумовой свуш.

## Переключатель
Иконка динамика в topbar (`#sound-toggle`): вкл/выкл, иконка on/off, `aria-pressed`,
сохранение в localStorage `hq_sound_v1` (по умолчанию — включён). Все play-функции сначала
проверяют флаг. AudioContext создаётся/резюмируется по первому жесту пользователя.

## Реализация
- `app.js`: модуль `Sound` (IIFE) — ctx/master, `tone()`, `swoosh()`, методы correct/wrong/
  hover/depart, toggle; `toggleSound()` + `updateSoundUI()`; вызовы в `answer()`; hover-
  слушатели на `.mode-card`/`.progress-nav`; инициализация.
- `index.html`: кнопка звука в topbar (два SVG on/off); на hero-кнопке — `Sound.depart()`.
- `styles.css`: стили `.topbar-sound` (+ `.topbar-right` группировка), состояние `.muted`.
