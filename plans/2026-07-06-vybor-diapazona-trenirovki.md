# План: выбор диапазона дат для тренировки (Квиз и Режим карточек)

Дата: 2026-07-06
Функция: перед запуском Квиза/Режима карточек ученик выбирает, ИЗ КАКИХ дат собирать раунды.
Диапазон работает ПОВЕРХ существующей механики раундов по 7 карточек — только сужает пул,
из которого случайно набираются карточки. Саму механику раундов, «сложные даты» и прогресс
не трогаем.

## Зачем
Ученик, выучивший пока первые 20 дат, тренируется именно на них и не встречает вопросы по
непройденным темам. Это снимает демотивацию.

## Механика
1. Новый экран-настройка `screen-setup` перед Квизом и Режимом карточек: пресеты + ручной
   диапазон (два `<select>` «с какой» — «по какую» по ПОРЯДКУ списка, не по годам).
2. Пресеты: «Первые 20», «Первые 50», «Все выученные» (по статистике прогресса), «Все N».
3. `buildSession(size, pool)` получает пул = карточки из диапазона; механика отбора та же.
4. Выбор диапазона хранится в localStorage (`hq_range_v1`), подставляется при след. заходе;
   изменить можно в любой момент перед раундом.
5. «Сложные даты» и прогресс работают как прежде, просто в рамках пула.

## Модель выбора
`rangeSel = { mode, from, to }`, mode ∈ {"all","mastered","range"}. Пул:
- all → все CARDS; mastered → CARDS.filter(isMastered); range → CARDS.slice(from, to+1).
Пресеты «Первые 20/50» = range 0..19 / 0..49. «Все N» = all. «Все выученные» = mastered.

- [x] Фаза 6. Визуальная иерархия экрана (2026-07-07). Раньше все элементы были однородны —
      непонятно, что делать в первую очередь. Что сделано:
      • Акцентный цвет по режиму: `openSetup()` проставляет `data-mode` ("quiz"/"flip") на
        `#screen-setup`; CSS-переменная `--setup-accent` = `--c-quiz` (зелёный) / `--c-cards`
        (оранжевый), плюс `--setup-accent-tint` для теней/обводки.
      • Пресеты — главный путь: крупнее (16px, padding 15×26); активный ЗАЛИТ акцентным цветом
        (белый текст, мягкая тень), а не просто обведён рамкой — сразу видно, что выбрано.
      • Ручной диапазон — второстепенный: облегчён (подложка `--bg`, пунктирная рамка, без тени)
        + подпись-разделитель «или выбери свой диапазон» (`.setup-range-label` в index.html).
      • Пояснение под заголовком приглушено (13.5px, `opacity .85`), kicker окрашен в акцент.
      • «Начать раунд» (`#setup-start`) залита акцентом и крупнее — доминирует над тихой
        ghost-кнопкой «В меню».
      Файлы: app.js (`openSetup`), index.html (подпись), styles.css (блок «ЭКРАН ВЫБОРА
      ДИАПАЗОНА»). Проверено превью-снимком обоих режимов через headless Chrome.
- [x] Фаза 7. Доводка композиции (2026-07-07). По обратной связи:
      • Пресеты вернули к компактному размеру (14px, padding 11×20) — акцент только цветом
        заливки активного, не размером кнопки.
      • Предсказуемая раскладка: `grid` — ряд из 4 авто-колонок по центру на десктопе,
        ровная сетка 2×2 (`repeat(2, minmax(0,1fr))`) на экранах ≤600px (без «переносов как
        получится»).
      • Контейнер `.setup` расширен 620 → 700px, чтобы всё располагалось просторно.
      • Блок ручного диапазона оформлен как цельный: во всю ширину контента (`width:100%`),
        больше внутренних отступов (22×26), мягкая подложка — уже не тесная узкая вставка.
      • Fix переполнения по горизонтали: `.range-field select { min-width: 0 }` — длинный
        текст опции больше не распирает контейнер на узких экранах.
      Проверено headless-снимками десктоп (ряд из 4) и мобильной (2×2, диапазон в колонку).
