# План: Деплой ХроноКвеста на Amvera Cloud

## Цель
Опубликовать статический сайт-тренажёр (HTML/CSS/JS, без бэкенда и БД, прогресс в localStorage) в интернете на хостинге Amvera Cloud, чтобы был публичный рабочий адрес.

## Решение
Сайт лежит в подпапке `app/`. Используем окружение **docker**: собираем образ по `Dockerfile`, который раздаёт содержимое `app/` через nginx. Наружу попадает только `app/` — папки `plans/` и `.business/` не раздаются.

Файлы конфигурации (в корне репозитория):
- `Dockerfile` — `FROM nginx:alpine`, `COPY app/ /usr/share/nginx/html/`, порт 80.
- `amvera.yml` — `meta.environment: docker`, `run.containerPort: 80`.

## Важные нюансы
- **Ветка сборки — `master`.** Amvera следит за `master`, а локально ветка `main`. Пушить нужно с маппингом: `git push amvera main:master`. Обычный `git push amvera main` заливает код, но сборку НЕ запускает.
- Первый push требует логин/пароль Amvera (вводит пользователь в своём терминале через `!команда`).
- Бесплатный домен создаётся во вкладке «Домены» → «Создать доменное имя» (внутренний адрес из интернета не открывается).
