# Пресет «Сложные» в выборе диапазона + быстрый вход из «Мой прогресс»

Дата: 2026-07-11

## Задача
1. Добавить кнопку-пресет «Сложные» на экран выбора диапазона (перед Квизом и Режимом карточек), рядом с «Первые 20 / Первые 50 / Все выученные / Все даты». Фильтрует пул до дат со статусом «сложная».
2. Если сложных дат нет — честно показать «В пуле 0 дат» + мягкое сообщение, кнопку «Начать раунд» сделать неактивной.
3. В разделе «Мой прогресс» при активном теге «Сложные» показать кнопку «Тренировать эти даты» → запуск Квиза (и Режима карточек) с уже выбранным пресетом «Сложные».

Переиспользовать существующую логику `hardCards()` — не создавать новую систему подсчёта.

## Ключевые точки в коде
- `hardCards()` (app.js:373) — источник истины «сложных дат». Используется и в «Моём прогрессе».
- Диапазон: `rangeSel`, `rangePool()`, `presetOf()`, `rangeLabel()`, `applyPreset()`, `syncSetupUI()` (app.js:390–1095).
- Пресеты в HTML: index.html:182–185.
- «Мой прогресс»: `renderProgress()` (app.js:1379), фильтр `hard` уже есть (index.html:331).

## Фазы

### [x] Фаза 1. Пресет «Сложные» на экране диапазона
- HTML: кнопка `data-preset="hard"` в `#setup-presets`.
- `rangePool()`: `mode === "hard"` → `hardCards()`.
- `presetOf()`: `mode === "hard"` → `"hard"`.
- `rangeLabel()`: `"hard"` → «Сложные».
- `applyPreset("hard")`: `rangeSel = {mode:"hard", ...}`.

### [x] Фаза 2. Честный пустой пул + блокировка старта
- `syncSetupUI()`: для `hard` — приглушить ручной диапазон (как у `mastered`), сводка «В пуле N сложных дат» / при 0 — «В пуле 0 дат. Пока нет сложных дат — отлично!». Кнопка старта уже блокируется при `n === 0`.

### [x] Фаза 3. Кнопка «Тренировать эти даты» в «Моём прогрессе»
- HTML: контейнер `#hard-train-cta` под подсказкой фильтра.
- `renderProgress()`: показывать CTA только при `progressFilter === "hard"` и наличии сложных дат.
- `trainHard(target)`: ставит `rangeSel = {mode:"hard"}`, сохраняет, запускает Квиз или Режим карточек.
- Стили кнопок в styles.css.

## Итог
Реализовано целиком. Все три фазы выполнены, пул «Сложные» переиспользует `hardCards()`.
