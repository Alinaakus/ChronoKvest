# Редизайн экранов 1 и 2 под новую дизайн-систему

Функция: визуальный редизайн лендинга (экран hero) и меню (экран menu) под новую тёплую
палитру в стиле «wellness»-референса. Логика, тексты и структура не меняются — только визуал.
Шрифт Inter (уже подключён).

## Дизайн-система (палитра)
- Фон страницы: `#F4F3EF`
- Карточки: `#FFFFFF`
- Акцент: `#DCE7F9` (светло-голубой), мелкие детали `#B8CFF2`
- Текст: основной `#1D1D1B`, вторичный `#6B6B66`
- Кнопки: тёмные `#1D1D1B`, белый текст, pill (radius 100px)
- Синий `#007AFF`/`#0A84FF` убран полностью, цифры статистики — тёмные
- Тени еле заметные: `0 1px 3px rgba(0,0,0,.05)`

## Фаза 1. Палитра и базовые элементы — [x]
- Переписан `:root` в `styles.css` (фон, акцент, тени, radius 20px).
- Кнопки → тёмные pill.
- Все точечные использования синего как цвета текста → тёмный (`card-date`, `stat-big`,
  `hero-year`, чипы, бейджи, точки прогресса, обводки фокуса).

## Фаза 2. Экран 1 (лендинг) — [x]
- `min-height: 100vh`, контент по центру по обеим осям.
- Порядок: кот → заголовок 52px/600 → подзаголовок 22px → 2 строки описания 16px → тёмная pill-кнопка (16px 40px).
- Отступы: кот→заголовок 24px, заголовок→подзаголовок 16px, подзаголовок→описание 12px, описание→кнопка 40px.
- Сияние за котом перекрашено в светло-голубое.

## Фаза 3. Экран 2 (меню) — [x]
- Контейнер `max-width: 1160px`, `padding-top: 80px`.
- Заголовок «ХроноКвест» 44px по центру, отступ снизу 64px.
- Единая сетка 3 колонки, gap 24px — для стат-карточек и карточек режимов.
- Стат-карточки: padding 24px, radius 20px, цифра 32px тёмная, подпись 14px вторичная.
- Карточки режимов одной высоты (stretch), padding 32px, radius 20px.
  «Обучение» — акцентная `#DCE7F9`, остальные белые.
- Эмодзи заменены на SVG-иконки (книга, мишень, график) в тёмных кружках 44px, иконка белая (правка в `index.html`).
- Текст методики: отступ сверху 96px, ширина 640px по центру, 15px вторичным.

## Фаза 4. Мобильная версия (≤768px) — [x]
- Карточки режимов в 1 колонку; стат-карточки — ряд по 3, компактнее (padding 16px, цифра 24px).
- Боковые отступы страницы 20px, между секциями 48px.
- Заголовки 32px, кнопка лендинга на всю ширину.
- Проверено headless-рендером: горизонтального переполнения нет (`scrollWidth == innerWidth`).
