# План: несколько формулировок события на одну дату

**Дата:** 2026-07-03
**Функция:** у каждой даты — массив формулировок одного события; в квизе показывается случайная. Тренирует узнавание даты по разным вариантам условия (как на реальном ЕГЭ).

**Стек:** тот же (HTML + CSS + JS, данные в `data.js`).

## Зачем

На ЕГЭ одно и то же событие спрашивают разными словами. Ученик должен узнавать дату по любой формулировке. Структура должна легко масштабироваться до 100 (и позже 800) дат — контент грузим постепенно, логику не переписываем.

## Что сделано

Поле `event` (одна строка) заменено на `events` (массив формулировок).
Первая в массиве — основная/официальная; остальные — альтернативные условия.

Формулировки для 3 дат:
- **VI–VIII века:** «Расселение славян на три ветви» (пока одна формулировка).
- **862 год:** «Призвание варягов» (осн.); «Призвание варягов, Рюрик в Новгороде».
- **882 год:** «Образование Киевской Руси» (осн.); «Поход Олега на Киев»; «Объединение Новгорода и Киева»; «Образование Древнерусского государства».

## Фазы

- [x] Фаза 1. Структура данных: `event` → `events` (массив) во всех карточках `data.js`, с комментарием-инструкцией.
- [x] Фаза 2. Помощники в `app.js`: `eventsOf(card)` (всегда массив, устойчив к старому `event`) и `pickRandom(arr)`.
- [x] Фаза 3. Обучение: показ основной формулировки + строка «Также встречается как: …» (новый блок `#learn-event-alts` в `index.html`, стиль в `styles.css`).
- [x] Фаза 4. Квиз: при показе вопроса `pickRandom(eventsOf(card))` — случайная формулировка.
- [x] Фаза 5. Проверка синтаксиса `node --check` для `data.js` и `app.js` — OK. (Проверку в браузере делает пользователь.)

## Как добавить формулировку

В `app/data.js` у нужной карточки в массиве `events` дописать новую строку в кавычках через запятую. Первая строка — основная. Логику менять не нужно.

## Итог

**Реализовано целиком.** Структура готова к масштабированию до 100+ дат: добавление вариантов — это только правка массива `events`, без изменения кода. Обучение показывает альтернативные формулировки, квиз выбирает случайную.

**Осталось / на будущее:**
- Наполнение до 100 дат (постепенно) — при вставке сразу закладывать `events` массивом.
- Возможно: помечать «основную» формулировку отдельно, если понадобится не только первая по порядку.
