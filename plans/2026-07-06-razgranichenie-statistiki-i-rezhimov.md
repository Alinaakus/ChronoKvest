# План: визуально разграничить статистику и карточки режимов в меню

Дата: 2026-07-06
Функция: на экране меню верхний ряд статистики (дней подряд / дат выучено / сложных дат) и
нижние карточки режимов выглядели одинаково (карточки с рамкой и тенью), хотя статистика не
кликабельна. Нужно интуитивное различие «данные ↔ кнопки».

## Выбранное решение (комбинация приёмов 1–5, основа — приём 4)
Статистику превращаем в ПЛОСКУЮ строку метрик: без фона, рамок, тени и `cursor:pointer`,
с тонкими вертикальными разделителями между тремя значениями. Карточки режимов оставляем
как есть (тень + hover-подъём + pointer). Так «приподнятость» = кликабельность закрепляется
только за режимами.

## Реализация
- CSS `.menu-tiles` → flex-строка (была grid из карточек); `.mtile` → без bg/border/shadow,
  `cursor:default`, центрирование, компактные отступы; `.mtile + .mtile` → `border-left`
  (разделитель). Числа чуть меньше (30px), подписи 13px.
- Мобилка: убраны правила «карточек» (padding 16/border-radius); строка метрик компактнее
  (число 21px, подписи 11px, иконки 13px) — чинит съезжавшую вёрстку.
- `.mode-card` не меняли — контраст обеспечивается их тенью/hover/pointer.
