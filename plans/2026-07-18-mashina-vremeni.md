# План: «Машина времени» на hero-экране

## Что делаем
На стартовом (hero) экране маскот становится кликабельным (в дополнение к кнопке
«Начать путешествие во времени»). По клику — плавная «фокус»-анимация (лёгкое
масштабирование + размытие фона) и появление карточки-«твита»: случайная
историческая дата, оформленная как пост в стиле соцсети X, с живым фактом.
Под постом — тихая ссылка «Узнать больше об этой дате» (ведёт на карточку в
обучении) и кнопка закрытия. Можно жать сколько угодно — каждый раз новая дата.

## Данные (отдельная структура)
Новый файл `timemachine.js` с массивом `TIME_POSTS` — независим от 101 карточки,
легко дополняется блоками. Формат записи:
```js
{
  year: "862 год",              // историческая дата = «дата поста»
  event: "Призвание варягов",   // подпись/тема
  author: "Новгородское вече",  // «имя аккаунта» в духе эпохи
  handle: "@novgorod",          // ник
  text: "…",                    // сам пост (с эмодзи/хэштегами)
  cardId: 2,                    // связь с реальной карточкой (для «Узнать больше»)
}
```
Первые 4 записи — из задания (862, 1547, 1861, 957). cardId: 862→2, 957→5,
1547→23, 1861→57 (по data.js).

## Механика
- `#hero-mascot` получает onclick/onkeydown → `openTimeMachine()` (role=button).
- Триггер только по клику пользователя (не авто при загрузке).
- `openTimeMachine()` берёт случайный пост (без повтора подряд), рендерит и
  открывает модалку с «пружинной» анимацией; фон размывается (backdrop blur).
- «Ещё дата» — перевыбор поста в открытой модалке.
- «Узнать больше об этой дате» → закрыть модалку + `openLearnAt(cardId)`;
  если cardId нет — ссылка скрыта.
- «Закрыть» — просто закрывает.

## Оформление (в духе Apple)
- Чистая воздушная карточка-твит: аватар (маскот) + имя + ник + дата, текст,
  тихий футер. Сдержанная палитра проекта.
- Spring-анимация появления (cubic-bezier с лёгким овершутом), мягкое размытие
  фона, один фокус за раз. Уважать prefers-reduced-motion.
