# План: ненавязчивый анонс платной версии на экране меню

Дата: 2026-07-06
Функция: компактная плашка-анонс будущей расширенной (платной) версии на втором экране
(меню), ниже четырёх режимов. Не баннер и не кнопка — просто анонс.

## Требования
- Текст: «+800 дат по истории — совсем скоро. Расширенная версия ХроноКвеста с полным охватом
  кодификатора ЕГЭ — по годовой подписке.» (адаптировано по месту).
- Визуально отличается от рабочих карточек режимов: приглушённый цвет + пунктирная рамка,
  читается как анонс, но аккуратно (не «заброшенно»).
- Без цены и без кнопки оплаты — функционал подписки не реализуем.

## Реализация
- HTML: блок `.soon-card` (не `<button>`, без onclick) после `progress-nav` в `#screen-menu`:
  иконка-искра + заголовок «+800 дат по истории» + бейдж «Скоро» + описание.
- CSS: пунктирная рамка `var(--line)`, прозрачный фон, текст `--muted`, акцентная иконка/бейдж
  на `--brand` (мягко). Никакого hover/transform (это не кнопка).
