# План: убрать «голубой прямоугольник» и сгруппировать даты по эпохам

## Что делаем
1. **Баг «голубой прямоугольник» под шапкой** на квизе/карточках. Это оказался не debug-элемент,
   а индикатор текущей позиции в «пути по эпохам» (`#path`) — ряд из 101 точки. Тёмная точка
   текущей даты имела светло-голубой ореол (`box-shadow` цвета `--tint`), остальные точки почти
   сливались с фоном → виден одинокий голубой блок. С 101 датой ряд переполнялся. **Убираем ряд.**
2. **Группировка списков дат по эпохам** — идея из принципов проекта («прогресс как история по
   эпохам»). Список 101 даты в «Мой прогресс» разбиваем на сворачиваемые секции-эпохи; в модалке
   быстрого перехода — заголовки-разделители по эпохам.

## Почему так
- Ряд из 101 точки не масштабируется и читается как артефакт → удаляем (функция `renderPath`
  оставлена безопасной заглушкой, чтобы вызовы из режимов не падали).
- Сворачиваемые секции по эпохам решают «длинный скролл» лучше пагинации (её откатили): свёрнуто —
  видно ~7 заголовков; и это отражает историческую «карту эпох».

## Эпохи (граница по году начала события, `to` не включается)
Древняя Русь (<1237) · Орда (<1480) · Московское царство (<1682) · Империя XVIII (<1801) ·
Империя XIX–нач.XX (<1917) · Советская (<1991) · Современная (∞).
Проверка на данных: 13/6/16/13/20/28/5 — все 101 разложены, пустых нет.

## Фазы
### [x] Фаза 1. Убрать ряд точек
Удалён `#path` из HTML; `renderPath` — guard `if(!path) return`; убрана строка display в `showScreen`.

### [x] Фаза 2. Группировка по эпохам
`EPOCHS`, `yearOf`, `epochIndexOf`, `groupByEpoch`. Прогресс: сворачиваемые секции (`toggleEpoch`,
`openEpochs`, `resetEpochDefaults` — мало дат раскрывает всё, много — свёрнуто). Откачена пагинация.
Модалка перехода: заголовки эпох при пустом поиске, плоский список при поиске.

### [x] Фаза 3. Проверка
`node --check` ОК; распределение по эпохам проверено скриптом на data.js; открыто в Chrome.

## Итог
Реализовано целиком. Голубой артефакт устранён (удалён ряд точек пути); списки дат сгруппированы по
7 историческим эпохам — компактно и в духе «истории по эпохам». Связано: [[2026-07-06-globalnaya-navigaciya]].
