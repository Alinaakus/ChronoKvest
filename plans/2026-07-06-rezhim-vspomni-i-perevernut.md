# План: режим «Вспомни и переверни» (тренировочный квиз)

## Что делаем

Второй режим квиза — **«Вспомни и переверни»** (рабочее название) как **альтернатива**, а не замена
существующему квизу с 4 вариантами.

**Механика:** крупная карточка с названием события («Крещение Руси»). Ученик сам, без вариантов,
вспоминает дату. Когда готов — кликает по карточке, она с анимацией переворачивается и показывает
правильную дату на обратной стороне. Дальше — к следующей карточке.

**Ключевое отличие:** режим **НЕ пишется в прогресс**. Не вызывает `recordAnswer()`, не меняет
статистику «сложные/выученные», не считается попыткой. Это чистая практика активного вспоминания
без давления оценки.

**Оба режима** доступны как отдельные пункты в меню:
- «Квиз» (4 варианта) — засчитывается в прогресс (как сейчас);
- «Вспомни и переверни» — тренировочный, без прогресса.

При входе показываем подсказку: «Это тренировочный режим для практики — сюда не идёт запись в прогресс».

## Почему так

По принципам проекта (CLAUDE.md): низкая цена ошибки, обучение через практику без стресса,
активное вспоминание — самый сильный способ закрепления. Отсутствие записи в прогресс снимает
давление оценки. Механику вспоминания-переворота (flip card) реализуем чистым CSS 3D-переворотом,
без библиотек (стек проекта — ванильные HTML/CSS/JS).

## Фазы

### [x] Фаза 1. Экран и карточка режима в меню
- В `index.html` добавить 4-ю карточку режима в `.mode-grid` → `onclick="startFlip()"`.
- Добавить новый `<section id="screen-flip">`: подсказка-плашка + сцена с переворачивающейся
  карточкой (лицо = событие, оборот = дата) + кнопки «Меню» / «Далее».

### [x] Фаза 2. Стили (CSS)
- `.train-note` — плашка-подсказка «тренировочный режим, без записи в прогресс».
- `.flip-scene` / `.flip-card` / `.flip-face` / `.flip-back` — 3D-переворот (`perspective`,
  `transform-style: preserve-3d`, `backface-visibility: hidden`, класс `.flipped`).
- Оборот — на зелёной подложке (`--good-tint`) как «раскрытие ответа».
- Меню: сетка режимов на 4 карточки (десктоп 4-в-ряд, планшет 2×2, мобилка — колонка).

### [x] Фаза 3. Логика (JS)
- `showScreen()` — добавить экран `flip` в список.
- `startFlip()` — перемешать колоду (лёгкая случайность), начать с первой.
- `renderFlipCard()` — показать событие (случайная формулировка), спрятать оборот, обновить путь.
- `flipCard()` — переворот карточки (toggle `.flipped`).
- `flipNext()` — следующая карточка / завершение сессии.
- **Проверка главного требования:** нигде в коде режима нет вызова `recordAnswer()` и записи в
  `progress` — прогресс не меняется.

### [x] Фаза 4. Проверка
- Открыть в Chrome, пройти режим, убедиться: переворот работает, дата верная, прогресс НЕ меняется
  (сверить плитки «выучено/сложные» до и после).

### [x] Фаза 5. Уточнение: имя и композиция меню
- Режим назван **«Режим карточек»** (механика «вспомни и переверни»).
- Меню пересобрано: три обучающих режима (Обучение · Квиз · Режим карточек) в ряд,
  а «Мой прогресс» вынесен отдельной широкой строкой-навигацией ниже (это раздел статистики,
  а не режим обучения) — `.progress-nav`.
- Под «Режимом карточек» добавлено пояснение: «Тренировка активного вспоминания — без записи в прогресс».

## Итог

Реализовано целиком. Добавлен отдельный тренировочный режим «Вспомни и переверни»: активное
вспоминание с переворотом карточки, отдельный пункт меню, подсказка при входе, полностью изолирован
от системы прогресса (не вызывает `recordAnswer`, не трогает `progress`). Существующий квиз с 4
вариантами не тронут.
