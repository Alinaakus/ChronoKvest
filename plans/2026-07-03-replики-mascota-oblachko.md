# План: реплики маскота в облачке (speech bubble) в квизе

**Дата:** 2026-07-03
**Функция:** заменить описательные подписи-реакции с эмодзи на прямую речь кота в диалоговом облачке (как в комиксах), с усилением реакции при верном ответе.

## Что делаем

1. Убрать эмодзи-иконки и подписи от третьего лица («Котик радуется…») из области реакции.
2. Верный ответ: маскот увеличивается/выделяется + облачко с прямой речью (рандом из набора). Объяснения от третьего лица нет.
3. Неверный ответ: облачко с прямой речью (рандом из набора). Пояснение «Правильно: …» + лайфхак — БЕЗ изменений (только убираем из него текст-реакцию перед ним).
4. Реплики не повторяются подряд (чтобы не приедалось).

## Ключевые правки

**app.js**
- Заменить массивы `HAPPY_REACTIONS`/`THINK_REACTIONS` на прямую речь от первого лица без эмодзи (`HAPPY_LINES`/`THINK_LINES`).
- `renderMascot(state, bubbleText)` — необязательный текст рисует облачко над котом.
- `pickFresh(arr, key)` — случайная реплика без повтора предыдущей.
- `answer()`:
  - верный: `renderMascot("happy", pickFresh(HAPPY_LINES,"happy"))`; область фидбэка — только кнопка «Дальше →», без зелёного текста-реакции.
  - неверный: `renderMascot("think", pickFresh(THINK_LINES,"think"))`; фидбэк = «Правильно: … лайфхак» (реплику-реакцию оттуда убрали).

**styles.css**
- `.bubble` — облачко (контур, скругление, хвостик через `::before/::after`), анимация появления.
- `.mascot` — плавный `transform`; `.mascot--happy` — увеличение (scale) для привлечения внимания (танец остаётся на `.cat-stage`).

## Итог

**Реализовано целиком.**
- Эмодзи-подписи от третьего лица убраны из области реакции.
- Верный ответ: кот увеличивается (`.mascot--happy` scale 1.16) и танцует, реплика — в комикс-облачке (`.bubble` с хвостиком), прямая речь из `HAPPY_LINES`. Область фидбэка — только кнопка «Дальше →».
- Неверный ответ: реплика в облачке из `THINK_LINES`; пояснение «Правильно: … + лайфхак» без изменений (убран только текст-реакция перед ним).
- `pickFresh(arr, key)` не повторяет предыдущую реплику подряд.
- Проверено рендером headless Chrome (верный и неверный ответ).

**На будущее:** реплики легко расширять — просто дописать строки в `HAPPY_LINES`/`THINK_LINES`. У некоторых дат-заглушек лайфхак пустой (`""`), поэтому в облачке пояснения он выглядит как один 💡 — это отдельная задача наполнения данных, не связана с реакциями.
